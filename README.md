## 🚀 Featured Projects

<details>
<summary><strong>🥛 Kumar Milk Distribution App (KMD) — Production-Grade Cross-Platform Application</strong></summary>

<br/>

**KMD** is a research-grade cross-platform mobile application designed to automate the end-to-end operations of small-scale milk distributors — covering order management, delivery scheduling, and payment processing. Built as a final-year group project and published at **ICSICE-2026**, the system addresses a real-world logistics gap in the informal distribution economy.

<br/>

| Attribute | Detail |
|-----------|--------|
| **Stack** | React Native · Expo · Node.js · Express.js · MongoDB Atlas · Razorpay · Mongoose |
| **Architecture** | REST API · Client-Server · NoSQL Document Model |
| **Scale** | Multi-tenant distributor onboarding · Order lifecycle management |
| **Security** | JWT Authentication · Role-based access · Secure payment gateway integration |
| **Impact** | Eliminates manual record-keeping · Automates payment reconciliation · Improves delivery SLA |
| **Research** | Published at ICSICE-2026 International Conference |

<br/>

The application was engineered by a team of four under the guidance of Prof. Asharani Shinde. The backend was architected using Node.js and Express with MongoDB Atlas as the primary data store, leveraging Mongoose for schema validation and data modeling. The Razorpay payment gateway was integrated for real-time transaction management. The frontend was developed with React Native and Expo to ensure cross-platform compatibility across Android and iOS.

Key engineering contributions included designing the backend data model for order and delivery workflows, structuring user data collection pipelines, and developing the API layer for seamless client-server communication.

<details>
<summary><strong>🤖 AI-Powered Chatbot — NLP-Based Campus Information System</strong></summary>

<br/>

An intelligent conversational agent engineered using Python to automate delivery of real-time campus event information. The system leverages TF-IDF vectorization and cosine similarity for intent classification and response retrieval from a curated knowledge base — a lightweight, interpretable NLP architecture without dependency on large language models.

<br/>

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python · TF-IDF · Cosine Similarity · NLP |
| **Architecture** | Retrieval-Based QA System · Knowledge Base Matching |
| **Scale** | College event information delivery · Real-time query resolution |
| **Performance** | Fast retrieval via vector similarity scoring |
| **Impact** | Reduced manual information-lookup overhead · Automated event query handling |
| **AI Method** | Unsupervised similarity-based retrieval — no labeled training data required |

<br/>

The chatbot was engineered to address the friction of manually querying campus event information. The core NLP pipeline performs tokenization, stopword removal, and TF-IDF vectorization of both the query and knowledge base corpus, then retrieves the highest-cosine-similarity response. The architecture is interpretable, low-latency, and extensible to broader domain knowledge bases.
